## Free GitHub Pages launch
1. Create a GitHub account.
2. Create a new public repository, e.g. `amir-realty-website`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select `main` and `/root`, then Save.
7. GitHub will provide the live `github.io` address.

For a professional domain such as `amirrealty.com`, register the domain separately and then connect it to GitHub Pages.
